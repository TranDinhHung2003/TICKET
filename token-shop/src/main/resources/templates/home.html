Hướng dẫn chạy tool

Sau khi mua, làm theo các bước sau để dùng Facebook Group Poster.

1. Thanh toán

Đăng nhập → chọn gói thời hạn → quét VietQR MB Bank hoặc chuyển khoản đúng nội dung FBPAY….

2. Nhận token

SePay báo có tiền → website tự tạo token đúng thời hạn bạn chọn → gửi Gmail + hiện trong Lịch sử mua hàng.

3. Kích hoạt & đăng bài

Mở app Facebook Group Poster → License → dán token → bắt đầu đăng nhóm. Mỗi token gắn 1 máy.
